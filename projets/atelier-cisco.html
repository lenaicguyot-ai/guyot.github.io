VLAN et routage sur équipements Cisco

Segmentation d'un réseau en VLAN et mise en place du routage pour faire communiquer les différents réseaux.

01 Contexte

Dans le cadre de l'atelier professionnel du BTS SIO option SISR à H3 Hitema, l'objectif était de concevoir et configurer l'infrastructure réseau d'une organisation sur des équipements Cisco. Un réseau « à plat », où tous les postes sont dans le même réseau, pose des problèmes de sécurité et de performance : on le découpe donc en VLAN, puis on configure le routage pour que les réseaux puissent communiquer.

03 Solution mise en œuvre

Les numéros de VLAN et les adresses ci-dessous sont des exemples : remplace-les par ceux de ton plan d'adressage.

  1. Plan d'adressage : un sous-réseau par VLAN. 
    VLAN 10  ADMIN   192.168.10.0/24  passerelle 192.168.10.254
VLAN 20  USERS   192.168.20.0/24  passerelle 192.168.20.254
  2. Création des VLAN sur le switch et affectation des ports en mode access : 
    vlan 10
 name ADMIN
interface range fa0/1-10
 switchport mode access
 switchport access vlan 10
  3. Liaison trunk (802.1Q) vers le routeur ou entre les switchs, pour faire passer plusieurs VLAN sur un même câble : 
    interface gi0/1
 switchport mode trunk
  4. Routage inter-VLAN (router-on-a-stick) : une sous-interface par VLAN sur le routeur. 
    interface gi0/0.10
 encapsulation dot1Q 10
 ip address 192.168.10.254 255.255.255.0
  5. Routage entre les routeurs : routes statiques vers les réseaux distants. 
    ip route 192.168.30.0 255.255.255.0 10.0.0.2
  6. Tests : ping entre les postes de VLAN différents, show vlan brief, show ip route, show interfaces trunk.
