Installation de GLPI sur Debian

Mise en place d'un outil de gestion de parc et de helpdesk sur un serveur Linux, avec une pile LAMP (Linux, Apache, MySQL, PHP).

01 Contexte

Dans le cadre de l'atelier professionnel du BTS SIO option SISR à H3 Hitema, l'objectif était de déployer un serveur de gestion de parc informatique. GLPI (Gestionnaire Libre de Parc Informatique) est un logiciel libre très utilisé en entreprise pour inventorier le matériel et les logiciels, et pour gérer les demandes d'assistance des utilisateurs (tickets).

C'est aussi l'outil que j'utilise en alternance chez WAAT pour traiter les demandes : ce projet m'a permis de comprendre comment il fonctionne côté serveur.

02 Besoin & cahier des charges

  • Serveur Debian
  • Pile LAMP
  • Base de données dédiée à GLPI
  • Accès à GLPI depuis un navigateur web
  • Comptes par défaut sécurisés

Contraintes : utiliser uniquement des logiciels libres, documenter chaque étape pour pouvoir refaire l'installation.

03 Solution mise en œuvre

  1. Préparation du serveur Debian : mise à jour du système, adresse IP fixe [à compléter : version de Debian, IP du serveur]. 
    apt update && apt upgrade -y
  2. Installation de la pile LAMP : serveur web Apache, base de données MySQL (MariaDB, la version fournie par Debian, compatible MySQL) et PHP avec les extensions nécessaires à GLPI. 
    apt install apache2 mariadb-server php libapache2-mod-php \
  php-mysql php-curl php-gd php-intl php-xml php-mbstring php-zip php-bz2 php-ldap -y
  3. Sécurisation de la base de données puis création de la base et de l'utilisateur dédiés à GLPI : 
    mysql_secure_installation
mysql -u root -p
CREATE DATABASE glpi;
CREATE USER 'glpi'@'localhost' IDENTIFIED BY 'motdepasse';
GRANT ALL PRIVILEGES ON glpi.* TO 'glpi'@'localhost';
FLUSH PRIVILEGES;
  4. Téléchargement de GLPI depuis le site officiel, décompression dans /var/www/ et attribution des droits à l'utilisateur d'Apache : 
    tar -xzf glpi-x.x.x.tgz -C /var/www/
chown -R www-data:www-data /var/www/glpi
  5. Configuration d'Apache pour publier GLPI, puis rechargement du service.
  6. Installation web : depuis le navigateur, assistant d'installation de GLPI : vérification des prérequis, connexion à la base de données glpi, création des tables.
  7. Sécurisation après installation : changement des mots de passe des comptes par défaut (glpi, tech, normal, post-only) et suppression du fichier d'installation.
